# 清爽收纳 v0.6.0 发布说明

> 本文件用于粘贴到 GitHub Release 的说明栏。

Windows 文件整理助手：扫描 → 预览 → 整理 → 撤销。
本地运行、不联网、不删除文件。操作记录只保存在你自己的电脑上。

## 本版本包含

1. **历史整理记录**：按批次列出每一次整理，可查看该批次实际移动成功的文件
2. **撤销本次整理**：把某次整理移动过的文件搬回原位置
   - 只撤销记录明确为「已移动」的文件
   - 原位置已有同名文件就跳过，绝不覆盖
   - 支持中途停止，准确统计成功 / 跳过 / 失败
3. **整理**：重名自动跳过、逐项复检、可随时停止
4. **安全机制**：不删除任何文件、路径越界拦截、符号链接/目录联接解析校验

## 使用说明

1. 双击 `清爽收纳.exe` 启动
2. 点「选择文件夹」，选一个要整理的目录（**建议先拿测试目录练手**）
3. 点「生成整理方案」检查预览，确认后点「确认整理」
4. 需要反悔时：页脚「历史记录」→ 选中那一次 →「撤销本次整理」

## 已知限制

- 只整理所选文件夹的**第一层**，子文件夹内容不会被移动
- 遇到重名一律跳过，不会自动改名
- 撤销后空的分类文件夹会保留（程序不删除任何文件）
- 整理过程中被强制结束的记录（状态「未完成」）不参与撤销
- 多个程序实例同时整理同一个文件夹没有加锁
